# CHAT REVIVE | Roblox Studio Portfolio

A Windows 98 themed portfolio showcasing Roblox Studio builds. Mobile-first, vertical layout inspired by straw.page.

## Deploy to Vercel

1. **Create a GitHub repository**
   - Go to [github.com/new](https://github.com/new)
   - Name it `portfolio` or `roblox-portfolio`
   - Do not initialize with README (this project already has one)

2. **Push this project**
   ```bash
   cd /Users/undefined1/Desktop/portfolio
   git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
   git push -u origin main
   ```

3. **Deploy on Vercel**
   - Go to [vercel.com](https://vercel.com) and sign in with GitHub
   - Click "Add New Project" → Import your `portfolio` repo
   - Vercel auto-detects static HTML (no build config needed)
   - Click Deploy

Your site will be live at `your-project.vercel.app`.
